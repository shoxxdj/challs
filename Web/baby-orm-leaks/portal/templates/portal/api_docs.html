ShadowCorp Internal API

Documentation interne de l'API REST du portail employés. Réservée aux développeurs et administrateurs système. Ne pas diffuser en dehors de ShadowCorp.

Base URL http://<host>:8000
Authentification
ℹ L'API utilise un système de filtres dynamiques. Le client envoie un objet filter contenant les critères de recherche en base de données.

Format de la requête

Toutes les requêtes authentifiées utilisent POST /api/login avec un corps JSON contenant la clé filter. Les valeurs du filtre sont passées directement au moteur de requêtes.

Endpoints
POST /api/login Authentifier un employé ▶
Corps de la requête
application/json 
{
  "filter": {
    "username": "john.doe",
    "password": "••••••••"
  }
}
Réponses
200 OK
403 Forbidden
Exemple 200 
{
  "id":          2,
  "username":    "john.doe",
  "email":       "john.doe@shadowcorp.com",
  "full_name":   "John Doe",
  "role":        "employee",
  "department":  "Engineering",
  "is_active":   true
}
GET /api/me Profil de l'employé connecté ▶
⚠ Admin uniquement : le champ secret_token n'est retourné que pour les comptes de rôle admin.
Exemple admin 
{
  "id":             1,
  "username":       "admin",
  "email":          "admin@shadowcorp.internal",
  "full_name":      "System Administrator",
  "role":           "admin",
  "department":     "IT Security",
  "is_active":      true,
  "secret_token":   "<token confidentiel>"    // champ interne, jamais exposé via /api/login
}
Modèle — Employee
⚠ Note interne : le champ secret_token est stocké en clair dans la base de données. Il ne doit jamais apparaître dans les réponses publiques de /api/login. Filtrage effectué dans public_data.
Champ Type Statut Description
id integer lecture seule Identifiant unique auto-incrémenté
username string requis Identifiant de connexion. Format : prenom.nom
email string requis Adresse email professionnelle
full_name string requis Nom complet affiché dans le portail
password string hashé Hash PBKDF2-SHA256. Jamais retourné par l'API.
role enum optionnel Rôle de l'employé : employee · manager · admin
department string optionnel Service de rattachement
is_active boolean optionnel Compte actif. Les comptes inactifs ne peuvent pas se connecter.
date_joined datetime lecture seule Date de création du compte
secret_token string interne Jeton confidentiel propre à chaque compte. Stocké en clair. Utilisé pour les intégrations système internes. Non inclus dans public_data — ne doit jamais être exposé côté client.
Codes d'erreur
CodeSignification
200 Authentification réussie — retourne les champs publics de l'employé
400 Corps JSON invalide ou filtre manquant / champ ORM inconnu
403 Identifiants invalides — aucun employé ne correspond au filtre
